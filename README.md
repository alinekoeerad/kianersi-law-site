## Technical Architecture

Developed with a focus on performance, scalability, and modern UI/UX principles:
* **Frontend:** React (v19) and TypeScript (v5.9) for a robust and type-safe application architecture.
* **Build Tool:** Vite (v7) for rapid development and optimized production builds.
* **Styling:** Tailwind CSS (v4.1) utilizing a formal, custom color palette to reflect a professional legal identity.
* **Deployment:** Containerized via Docker and configured for automated deployment on GitHub Pages.

* **Responsive & Accessible UI:** A fully fluid design that adapts flawlessly to mobile, tablet, and desktop environments.

## Local Development Setup

To run this project locally, follow these steps:

1. **Clone the repository:**
```bash
   git clone [https://github.com/alinekoeerad/kianersi-law-site.git](https://github.com/alinekoeerad/kianersi-law-site.git)
   cd kianersi-law-site

```

2. **Install dependencies:**

```bash
   npm install

```

3. **Start the development server:**

```bash
   npm run dev

```

## Docker Deployment

The application includes a `Dockerfile` for streamlined containerization:

```bash
docker build -t kianersi-law-site .
docker run -p 8080:80 -d kianersi-law-site

```

The application will be accessible at `http://localhost:8080`.
