## 🚀 Local Setup & Development

Follow these steps to run the project locally on your machine:

### 1. Prerequisites

* **Node.js** (v18 or higher recommended)
* **npm** or **yarn**

### 2. Install Dependencies

Clone the repository and install the required packages:

```bash
git clone [https://github.com/alinekoeerad/kianersi-law-site.git](https://github.com/alinekoeerad/kianersi-law-site.git)
cd kianersi-law-site-main
npm install

```

### 3. Run Development Server

```bash
npm run dev

```

The project will be available at `http://localhost:5173` (or a similar port).

---

## 🐳 Running with Docker

If you prefer to run the project using Docker:

```bash
# 1. Build the Docker image
docker build -t kianersi-law-site .

# 2. Run the container
docker run -p 8080:80 -d kianersi-law-site

```

The website will be accessible in your browser at `http://localhost:8080`.

## 🌐 Deployment

This project is configured for automated deployment to **GitHub Pages**. To deploy new changes:

```bash
npm run deploy

```

This command builds the production version and pushes it to the `gh-pages` branch.

> **Note:** Make sure your GitHub repository settings (Settings > Pages) are configured to serve from the `gh-pages` branch.
